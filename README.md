# 期待値ラボ

賭ける前に、数字を見る。 — パチンコ・スロット・オリパ・ガチャ・ルーレットの
**期待値と確率をシミュレーションする学習ツール**です。

**実際のお金は一切使いません。** すべての通貨・コイン・チップは架空のもので、
金銭を賭ける行為を推奨するものではありません。

## できること

| タブ | 内容 |
| --- | --- |
| パチンコ | 大当たり確率・回転数・出玉振り分けからボーダーと期待収支をモンテカルロ推定 |
| スロット | AT機 / Aタイプの機械割・破産確率。総ゲーム数指定と投資金額指定の2モード |
| 設定判別 | 実戦のBIG/REG/子役をタップでカウントし、設定1〜6の期待度を二項尤度で比較 |
| オリパ | 等級・封入枚数から還元率を算出。保証枠つきで実際に引ける |
| ガチャ | 排出率と天井から期待値を算出。実際の排出割合を理論値と比較 |
| ルーレット | 本格カジノ盤(ヨーロピアン/アメリカン)。友達対戦とベット戦略の比較 |
| カスタム抽選 | 任意の項目と重みでホイールを作る。子項目の二段階抽選つき |
| 統計 | 実践収支の記録とシミュ結果の生涯収支 |

## 使い方

ブラウザで開くだけで動きます。インストール不要ですが、PWAとして
**ホーム画面に追加するとオフラインでも起動**します。

データはすべてブラウザの localStorage に保存され、サーバーへは送信されません。

## 開発

単一HTML(`ev-lab.html`)で完結する構成です。ビルド手順はありません。

```bash
cd tests && npm install && npm test   # 回帰テスト(全7スイート)
python tools/make-icons.py            # アイコン再生成
```

- `tests/` … jsdom による回帰テスト。詳細は [tests/README.md](tests/README.md)
- `tools/make-icons.py` … PWA/ストア用アイコンの生成
- `CLAUDE.md` … 設計判断と実装経緯の記録

## 免責

- 本アプリは確率の学習・可視化ツールであり、金銭を賭ける行為を推奨するものではありません
- 実在の機種・メーカーとは一切関係ありません
- 理論値は条件を無限に繰り返した場合の平均です。シミュレーションや実引きは乱数による一例で、毎回変わります
